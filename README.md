# Tiller

Turn your coding agents into repeatable visual workflows. Free and open source (MIT).

This repo holds Tiller's releases, issues and feedback. The source code lives at
[0xNull-ops/tiller](https://github.com/0xNull-ops/tiller).

- Website: https://tiller.shipr.app
- Download: [latest release](https://github.com/Antler-Web-Studios/tiller/releases/latest), or `brew install --cask antler-web-studios/tap/tiller`
- Report a bug or request a feature: [open an issue](https://github.com/Antler-Web-Studios/tiller/issues)

Tiller requires a Mac with Apple Silicon.
